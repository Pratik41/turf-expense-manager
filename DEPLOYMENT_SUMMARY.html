🚀 Deploy in 3 Steps

1

Create Firebase Project (5 min)

Go to firebase.google.com

  • ✓ Create project: "turf-expense-manager"
  • ✓ Enable Firestore Database
  • ✓ Enable Email/Password Auth
  • ✓ Enable Hosting
  • ✓ Copy Firebase config from Project Settings
2

Update Firebase Config

Edit js/config.js with your Firebase credentials:

const firebaseConfig = { apiKey: "YOUR_API_KEY", authDomain: "YOUR_PROJECT_ID.firebaseapp.com", projectId: "YOUR_PROJECT_ID", storageBucket: "YOUR_PROJECT_ID.appspot.com", messagingSenderId: "YOUR_SENDER_ID", appId: "YOUR_APP_ID" };
3

Deploy

npm install -g firebase-tools firebase login firebase deploy

✓ Your app is live! You'll get a URL like:
https://YOUR_PROJECT_ID.web.app
